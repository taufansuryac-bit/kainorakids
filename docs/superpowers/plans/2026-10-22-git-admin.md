> For agentic workers: execute inline using executing-plans. Preserve existing uncommitted work; no commits, pushes, billing, DNS or website deployment. Later explicit approval adds dedicated Spark Firebase provisioning and Auth/rules deployment, documented below.

**Goal:** Build the approved catalogue/highlights/3D CMS and an activation guide for the owner's new Cloudflare account.
**Architecture:** Shared validated JSON content, React editor, GitHub App OAuth/Cloudflare API adapter with atomic Git commits. Explicit loopback-only Vite admin mode for local verification.
**Tech Stack:** existing React/Vite/Three.js, Node test runner, Web Crypto, Cloudflare Pages Functions, GitHub REST.
**Spec:** ../specs/2026-10-22-git-admin-design.md

## Global constraints
- max 12 highlights; only catalogue IDs; separate 3D collection; no fabricated commerce data.
- Transparent PNG for artwork; fixed presets; white/black; front/back initial view; only center rotates.
- No tokens in client, no unauthenticated production writes, no overwrite on conflicting revision.

## Review focus
- Empty catalogue/3D/highlights must stay empty after reload.
- Delete linked catalogue item clears highlight and 3D CTA.
- Interrupted upload/publish leaves previous content intact; stale editors receive conflict.
- Wrong origin, user or forged session cannot commit; local adapter cannot be exposed to LAN.
- One, two or >5 garments navigate correctly; image changes retain print position and alpha.
